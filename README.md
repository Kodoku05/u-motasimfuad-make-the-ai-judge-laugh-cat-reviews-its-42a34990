A one-star review written by a house cat about its human: the cat counts its owner's petting strokes, finds affection rationed, and takes revenge on the favourite glass — then confesses it was not an accident. The program writes the line to `/output/entry.txt` (159 Unicode code points, inside the 1–200 gate) and fails closed if the text ever falls outside the gate.

## Run it

```sh
node main.ts
```
